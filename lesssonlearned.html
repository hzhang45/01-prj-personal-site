Lessons Learned in CS100

Over the semester I have learned so much useful information from the history of how the concept of comuters and computing was started, to now coding my own webpage in html.

If I had to pick, my favorite lesson would be the python drawing lessons using turtle. I learned to draw different shapes, spider webs, even exciting faces. It was the first time I was ever exposed to python and I had a great experience. I remember messing with the code in class to make different objects and all the fun challenges we had to do. I recall in one of the homeworks making this face to the right and taking forever to get the eyes in the right place. I also learned how to use two different kinds of ciphers to encode my messages, which I will probably use to mess with my friends.

Another valuble lesson that I learned was about cyber security and artificial intelligence. The homeworks got me to research real world hacks that had happened and how they affected people. Before I've always head of how dangerous hackers were but I kind of took that for granted since it has never happened to me; but actually seeing the data and how easily hackers can get access to your sensitive personal information has gotten me to take cyber security a lot more seriously.
